## [0.1.0] - 2026-09-10

### Added
- Initial public release
- Core deployment framework with state machine
- Robot support: Go1, Go2, Duow, Go2W, M20, G1
- Simulation: MuJoCo, MuJoCo GLFW, Gazebo
- Policy implementations for various locomotion and manipulation skills
- User control interfaces (keyboard, Xbox controller, mobile web)
- Documentation in Chinese and English
